# HackMate Backend
This repository contains the backend of **HackMate**, a MERN Stack application that helps students find teammates for hackathons, college projects, and coding competitions.

The backend provides secure authentication, team management, profile management, and real-time chat using Socket.IO.


## Features

- User Registration
- User Login
- JWT Authentication
- User Profile API
- Create Team
- Edit Team
- Delete Team
- Join Team
- Leave Team
- Real-time Team Chat
- MongoDB Database
- REST APIs

## Installation

Clone the repository

```bash
git clone https://github.com/Pranitha2807/hackmate-backend.git
```

Move into the project

```bash
cd hackmate-backend
```

Install dependencies

```bash
npm install
```

Create a `.env` file

```env
PORT=5000
MONGO_URI=your_mongodb_connection
JWT_SECRET=your_secret_key
```

Run the server

```bash
npm start
```

or

```bash
npm run dev
```
